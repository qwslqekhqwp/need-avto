# Need-Авто — лендинг

Сайт автотехцентра и шиномонтажа Need-Авто (Иваново, 16-я линия).

- `index.html` — страница выбора варианта
- `red/` — вариант A «Техцентр» (чёрный · белый · красный)
- `yellow/` — вариант B «Гараж» (чёрный · жёлтый)
- `assets/` — логотип в SVG и иконки

Чистый HTML/CSS/JS, сборка не нужна: откройте `index.html` в браузере.
